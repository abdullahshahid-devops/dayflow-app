# 💜 DAYFLOW

A modern daily productivity dashboard to organize routines, track progress, and build consistency.

## ✨ Features

- Daily productivity score
- Work tracking
- Prayer tracking
- Nutrition tracking
- Exercise tracking
- Weekly progress visualization
- Daily streak tracking
- Interactive and responsive dashboard

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- Nginx
- Docker
- Docker Compose

## 🚀 Quick Start

### Prerequisites

- Docker
- Docker Compose

No Node.js or npm required.

### 1. Clone the repository

    git clone https://github.com/abdullahshahid-devops/node-todo-gitlab-cicd-aws.git
    cd node-todo-gitlab-cicd-aws

### 2. Build and start DAYFLOW

    docker compose up -d --build

### 3. Open DAYFLOW

    http://localhost:8080

## 🐳 Useful Docker Commands

Check status:

    docker compose ps

View logs:

    docker compose logs -f

Restart:

    docker compose restart

Stop:

    docker compose down

Rebuild:

    docker compose up -d --build
